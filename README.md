# Price Action бот (Bybit, USDT-фьючерсы)

Скальпит самые волатильные монеты по price action на минутках. Стоп ставит за структурой с запасом, тейк 1:2.
Встроенная нейросеть учится сама: на истории при первом запуске и дальше на каждом сетапе, который видит на рынке.

**По умолчанию торговля бумажная** — реальные цены Bybit, но без ордеров. Реальный счёт включается переменной
`LIVE=1` (плюс ключи `BYBIT_API_KEY` / `BYBIT_API_SECRET`).

## Как торгует

Каждую минуту:

1. **Монеты.** Из USDT-фьючерсов с оборотом от 20M$ за сутки берёт 45 самых ликвидных и выбирает `--top 10` с самым большим
   средним размахом минутной свечи за последний час. Монеты, улетевшие за сутки больше чем на ±80%, не берёт.
   Монеты можно вписать на странице — тогда торгует только их.
2. **Сетапы price action** на последней закрытой минутке (`pa.py`):
   - **sweep** — снятие ликвидности: хвост прокалывает недавний swing-уровень, свеча закрывается обратно. Вход против прокола.
   - **retest** — пробой swing-уровня закрытием, откат к уровню, удержание. Вход по направлению пробоя.
   - **pullback** — тренд на 5м (EMA20 > EMA50 с наклоном), откат к EMA20 на 1м с отбоем. Вход по тренду.
3. **Умный стоп.** Не на экстремуме, а за ним с запасом 0.25 / 0.5 / 1 ATR — какой запас лучше, решает сеть.
   Если рядом за стопом лежит ещё один swing-экстремум (там стоят стопы толпы), стоп уносится за него.
   Стоп не ближе 0.6 ATR и 0.25% (иначе выбьет шумом или съедят комиссии).
4. **Тейк** = 2 × риск (`--rr 2`), и только если до ближайшего встречного уровня есть место минимум 1.2R (`--min-room`).
5. **Сеть** оценивает каждый вариант в R (с комиссиями). Вход — если сеть «в форме» и ждёт ≥ 0.15R (`--min-edge`).
6. **Риск** — 0.5% баланса на сделку (`--risk-pct`), объём не больше 3 × баланс, до 3 сделок одновременно,
   одна на монету. Выход по тейку, стопу или через 60 минут. На реальном счёте стоп и тейк ставятся на бирже сразу после входа.
7. **Тормоза:** за сутки −4R — новых сделок до следующих суток UTC; 4 стопа подряд — пауза 60 минут.

## Как учится сеть (`brain.py`)

- **Первый запуск:** скачивает 3 дня минутных свечей по 25 самым волатильным монетам, находит в истории все сетапы
  и размечает их тем, что было дальше (тейк +2R, стоп −1R, выход по времени). Обучается.
- **Дальше каждую минуту:** все новые сетапы (взятые и нет) ждут исхода и идут в обучение. Свои сделки — с весом ×3.
  Память — 7 дней, свежие примеры весят больше (вес вдвое меньше каждые 24 часа). Полное переобучение раз в 30 минут
  с ранней остановкой по отложенному свежему куску.
- **Онлайн-проверка:** каждый сетап сеть оценивает ДО исхода. Торговать сеть себе разрешает, только если за последние
  6 часов её отобранные сетапы по факту дали в среднем больше +0.05R (минимум 20 итогов). Пока онлайн-итогов мало —
  смотрит на проверку на отложенном куске.

## Страница

Состояние, баланс и кривая баланса, открытые и закрытые сделки (в R и $), сетапы этой минуты с прогнозом сети, графики сети
(онлайн-проверка, память, ошибка по эпохам, важность признаков), «мысли» сети, самые волатильные монеты, лог.
Кнопки «Старт» / «Стоп» (стоп закрывает сделки и не даёт открывать новые) и поле монет. `CONTROL_KEY` защищает кнопки.

## Railway

- Подключи репозиторий, смонтируй том на `/data` (там память сети, сделки, баланс).
- Переменные: `CONTROL_KEY` (ключ для кнопок). Для реального счёта — `LIVE=1`, `BYBIT_API_KEY`, `BYBIT_API_SECRET`.
- Параметры — в `BOT_ARGS`, например `--risk-pct 0.3 --rr 2 --top 8`.

## Параметры (`BOT_ARGS`)

| Флаг | По умолчанию | Что делает |
|---|---|---|
| `--live` | выкл | реальный счёт (то же, что `LIVE=1`) |
| `--paper-balance` | 200 | стартовый бумажный баланс, $ |
| `--risk-pct` | 0.5 | риск на сделку, % баланса |
| `--rr` | 2 | тейк = RR × риск |
| `--max-open` | 3 | сделок одновременно |
| `--leverage` | 10 | плечо на бирже (влияет только на маржу; размер задаёт риск) |
| `--max-notional-x` | 3 | объём сделки не больше X × баланс |
| `--max-hold` | 60 | минут держать сделку |
| `--day-loss-r` | 4 | дневной лимит, R |
| `--loss-streak` / `--streak-pause` | 4 / 60 | стопов подряд → пауза, мин |
| `--symbols` | — | монеты через запятую (иначе самые волатильные; страница главнее) |
| `--top` / `--learn-top` | 10 / 25 | монет торговать / на скольких учиться |
| `--min-turnover` | 20000000 | мин. оборот за 24ч |
| `--max-24h` | 80 | не брать монеты, улетевшие за сутки больше ±X% |
| `--min-risk-atr` / `--max-risk-atr` | 0.6 / 4 | стоп от и до, ATR |
| `--min-risk-pct` | 0.25 | стоп не ближе X% |
| `--min-room` | 1.2 | до встречного уровня минимум X R |
| `--min-edge` | 0.15 | входить, если сеть ждёт ≥ X R |
| `--history-days` | 3 | история для первого обучения |
| `--memory-days` | 7 | память сети |
| `--online-hours` / `--min-online` / `--min-online-r` | 6 / 20 / 0.05 | онлайн-проверка |

## Файлы

- `bot.py` — монеты, свечи, решения, сделки (бумага и реальный счёт), главный цикл
- `pa.py` — структура, сетапы, умный стоп, признаки, разметка исхода
- `brain.py` — нейросеть (numpy), память, обучение, онлайн-проверка
- `web.py` — страница

Важно: результаты на прошлом и бумажная торговля не гарантируют прибыль на реальном счёте. Сначала смотри
бумажную торговлю минимум неделю: средняя сделка в R, доля тейков, худший день.
